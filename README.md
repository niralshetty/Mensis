## PROJECT NAME - MENSIS
# Description - Mensis is a Period Tracker which monitors the menstrual cycle to predict start and end date of your cycle and, it provides insight on what to expect during different phases of cycle. By logging in your symptoms and mood on a regular basis, it can also provide you information about what to expect in the beginning of your cycle. It also provides tips to take care of yourself based on the phase of cycle you are in. It is also helpful to those who are trying to concieve or avoid pregnancy altogether.
# Languages used - Python, HTML, CSS

# STRUCTURE OF THE CODE
  1. Database      - tables, and a helper to open them
  2. Cycle maths   - one function that the dashboard and calendar both use
  3. Pages         - login, signup, onboarding, home, calendar, settings
  4. Small APIs    - save a daily log, toggle a period day
  5. Email         - reminder sender 
  6. Templates     - the HTML template (Jinja)
  7. CSS           - design
